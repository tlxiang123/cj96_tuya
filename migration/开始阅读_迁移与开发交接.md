## 3. 新电脑操作步骤

1. 获取上述 GitHub 分支，或解压源码 ZIP。可在分支页使用 Code → Download ZIP，注意不要误下 main。
2. 准备 Python 3、Node.js（包含 npm）和涂鸦小程序 IDE。下面记录的是旧机本轮实测版本，不是最新版本或全部版本兼容性承诺。
3. 打开终端到工具所在目录：GitHub 版为 migration，ZIP 版为解压根目录。依次执行：

    python dev.py verify
    python dev.py doctor
    python dev.py install
    python dev.py build

4. 如需回归测试，再执行：

    python -m pip install -r requirements-tests.txt
    python dev.py test

5. 开发监听：

    python dev.py start

6. 在涂鸦小程序 IDE 用自己的正常账号登录，打开含 project.tuya.json 的 APP 根目录：GitHub 版为仓库根目录，ZIP 版为 panel。构建目标为 APP 根目录下 dist/tuya，项目 miniprogramRoot 已指向此处。
7. 确认账号有原 projectId 对应项目及设备权限，再预览/真机调试。不要新建不相关项目覆盖 projectId，不迁移登录 Cookie 或令牌。
8. 本轮没有代替你发布、上传涂鸦平台或连接真机；GitHub 上传与涂鸦平台发布是两回事。

### 工具说明

- dev.py 是 Python 3 实现，通过 subprocess 调用现有 Node/npm/Yarn，不依赖 PowerShell/BAT 脚本。
- install 优先找 Yarn Classic 1.22.22；找不到则仅在工具目录 .tools/yarn 安装此固定版本，不全局修改环境。
- 随后用 Yarn frozen lockfile 安装依赖。不要删除 yarn.lock，不使用缺少锁文件的 npm ci，不为迁移随意升级依赖。
- install 需要联网，会执行依赖正常安装生命周期；不是离线包。源站按 .npmrc。工具不改变系统代理、适配器或虚拟机设置。
- Node 不在 PATH 时通过 --node 指定 node.exe；npm 无法定位时用 --npm-cli 指定 npm-cli.js；Yarn 版本不对时用 --yarn-js 指定 yarn.js。参数可用 python dev.py --help 查看。
- test 的 --dependency-panel 仅显式借用另一已有工程的 node_modules。本轮打包测试用了它，新机正常安装后不需要。
- verify 检查快照损坏；正常开发修改会造成哈希不匹配，不要拿旧快照覆盖新代码。新增文件不在校验范围。
- package.json 的 lint 带 --fix，会修改源码，不是只读检查。

## 5. 用户已明确的界面要求

原则：APP 尽量与本地 CJ96 屏幕一致，图片和文字分离；不仅外观相似，按钮实际点击也应有效。分步骤调整，不随意改业务/通信逻辑。

### 底部五个按钮

- 总览、设备、计划、测试、日志。
- 使用本地 70×70 图标素材，独立 Text 文字，不把文字烘焙进图标。
- 保留五个原点击处理，设备按钮仍打开设备窗口。

### 设备列表

- 底部顺序：点击添加、总线设备 N、三个空白区域、同步。
- 用户明确说未添加和清除表格只是本地调试用，APP 不需要；不要恢复。
- 底部滚动按钮可重复点击，用交替 scrollTop 触发。

### 设备编辑 / 阀组区域

- 地址定位图、名称图、工具图与文字分别显示。
- 地址和阀组号用三个独立数字框显示，数字加粗。
- 列表显示四行，超出用真实 ScrollView，不与底部按钮重叠。
- 一键添加、取消、确认用透明边框底图加独立文字。
- 关联/清空/删除/修改名称工具用本地图标加独立文字。
- 名称、地址和组号来自动态状态，不硬编码截图里的示例数据。

### 最近一次四种弹窗按钮

- 共用 showW2GroupChoice 的 bind / clear / delete / rename 四种模式。
- 使用 confirm_cancel_bg_120x60.png 透明原生边框，单独 Text 文字。
- 取消在左、确认在右；全部只出现在 bind 和 clear。
- 去掉旧的对勾、叉号、方框装饰，字号按本地 20px 比例，正常字重。
- 图片/文字层 pointer-events:none，点击由外层控件处理。
- 保留原确认/取消/全部处理、左右箭头、数字输入及边界逻辑。
- 只完成这四种共享弹窗。容量、深层改名输入、绑定页面、雨量/湿度等其他弹窗仍需逐项审查，不能说全 APP 已统一。
